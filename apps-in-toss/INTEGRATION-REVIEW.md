# 메인 작업 인수 검토

별도 task-10의 `8c58b86` 기준 준비본을 독립 `apps-in-toss/`로 인수했다. 기존 web/mobile/desktop/backend에는 덮어쓰지 않았다. node_modules 및 진단 캐시는 복사하지 않았다.

후속 웹 `d8b2888`은 native permission 응답과 브라우저 알림 취소 경합만 수정한다. Toss는 알림 코드를 포함하지 않아 적용할 런타임 수정이 없다. `65626f0`은 Expo HTML의 사용자 ID 선언 및 Supabase 번들이다. Toss에는 Supabase 인증이나 Expo HTML이 없어 적용 대상이 아니다. 이 기능들을 Toss에서 지원한다고 표시하지 않는다.

원본 adapter/repository 및 생성 변환을 읽고, 인수한 복사본의 저장소 테스트 4/4를 실행해 통과했다. SDK/프로덕션 빌드는 별도로 검증하며, 실제 QR/기기/콘솔 업로드를 통과했다는 뜻이 아니다. root CI에 저장소 테스트를 포함한다. 동기화 스크립트는 특정 PC 경로 대신 이 저장소 루트를 참조하도록 수정했다.

예약되지 않은 후보 appName `oharu` 및 제출 문구는 실제 계정 승인 후 확정해야 한다. 현재는 무료 기기 내 저장 미리보기다. 계정 동기화·알림·결제·10개 테마·AI 연결은 이 adapter에서 제공하지 않는다. 기존 핵심 앱과의 기능 차이를 숨기지 않는다.
